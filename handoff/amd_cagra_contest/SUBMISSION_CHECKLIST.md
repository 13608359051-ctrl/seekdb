# 提交前检查清单

## 代码

- [ ] 参赛 commit 是冻结基线 `ad3253a5...`（或主办方最终指定 commit）的后代

- [ ] 从干净 checkout 可以用官方编译命令从源码构建
- [ ] 没有提交预编译 seekdb / bridge / 第三方二进制作为运行产物
- [ ] `lib=vsag` CPU 路径仍可工作
- [ ] 没有修改评测数据、输入精度、SQL 语义或固定测试
- [ ] 没有针对数据硬编码

## GPU

- [ ] 构建/查询真实执行 hipVS/cuVS CAGRA
- [ ] trace 有 `cuvs_build` / `cuvs_serve`（或等价可核验证据）

- [ ] 没有静默回退 VSAG/CPU 来冒充 GPU

## 性能

- [ ] 基线/候选使用同一 GPU、数据、参数、轮次

- [ ] 构建加速比可重复
